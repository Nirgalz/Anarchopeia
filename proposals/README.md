# Proposal catalogue

A **proposal** contains its claim or institutional design, its argumentation, evaluation, summary, research, source leads, and revision history **in one document per language**. No separate `research/` or `sources/` repositories are required.

| ID | Proposal | Status | Approved version |
| --- | --- | --- | --- |
| AP-0001 | [Aims](0001-aims/en.md) | `in_progress` | None |
| AP-0002 | [Emancipation](0002-emancipation/en.md) | `in_progress` | None |
| AP-0003 | [Domination](0003-domination/en.md) | `in_progress` | None |

The three status values are `in_progress`, `awaiting_approval`, and `approved`. A revision uses the **same** cycle; `revision_approved` is a decision event, not a fourth status. Unapproved versions are never placed in the manifesto.

For a new proposal, copy the [proposal template](../PROPOSAL_TEMPLATE.md) into `proposals/<four-digit-id>-<english-slug>/en.md` and add translations such as `fr.md`. Consult the [workflow](../WORKFLOW.md).
