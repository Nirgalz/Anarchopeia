# Sources and evidence

This directory will collect traceable bibliographic and empirical references. **No bibliography has yet been verified or imported.**

For each source, record author or institution, title, publication date, stable URL or DOI, type of evidence, relevant claims, methodological limitations, and where it is cited.

Distinguish primary evidence, interpretation, opinion, and unverified assertion. Citing an author does not imply agreement with their politics or all their claims.
