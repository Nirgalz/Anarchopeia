# Contribuer à Anarchopoeia

Toutes les contributions, y compris les objections aux concepts fondateurs, sont bienvenues. L'adhésion aux propositions du projet **n'est pas** une condition.

## La proposition est l'unité de travail

Pour toute modification substantielle du manifeste, y compris de ses finalités, principes, définitions ou règles de gouvernance, créer ou réviser une [proposition](proposals/README.fr.md) numérotée selon le [modèle](PROPOSAL_TEMPLATE.fr.md). Chaque proposition réunit problème, objectifs, mécanisme proposé, alternatives, critiques, évaluation, texte proposé pour le manifeste, recherche, références et historique **dans le même document**. Attribuer **une seule catégorie principale** et, si pertinent, **des catégories secondaires**, en utilisant les identifiants `anarchopeia`, `governance`, `economy`, `information` (voir le [catalogue thématique](proposals/README.fr.md)). Les catégories ne déterminent ni le statut d'approbation ni le chemin des fichiers.

1. Consulter les [Issues](https://github.com/Nirgalz/Anarchopeia/issues) avant de soulever une question, une objection, une alternative ou un problème documenté.
2. Distinguer faits, valeurs et hypothèses ; citer les sources, exposer loyalement les éléments contraires et signaler les incertitudes.
3. Ouvrir une pull request pour modifier les textes, en expliquer les motifs, lier les Issues et signaler les traductions à revoir.
4. Passer une version candidate à `awaiting_approval` pour solliciter une décision. L'initiateur est actuellement le seul responsable éditorial ; il ne s'agit pas d'une ratification collective.
5. Après **approbation explicite**, actualiser la version, la décision et le texte approuvé dans le [manifeste](manifesto/fr.md). La fusion d'un brouillon **ne vaut pas approbation**.

Critiquer les arguments plutôt que les personnes. Protéger la participation respectueuse et la possibilité de remettre en question les fondements du projet.

Lire le [workflow](WORKFLOW.fr.md), la [gouvernance provisoire](GOVERNANCE.fr.md) et le [guide des traductions](i18n/README.fr.md). Les anciennes notes de travail ont été retirées de l'arborescence active ; les propositions peuvent citer les versions historiques sans en présumer l'adoption.
